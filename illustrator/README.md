# Illustrator bridge

Claude writes layered line-art SVGs (`generators/`) and, optionally, drops job files that a small CEP panel in Illustrator 2024 executes.

## Without the panel
Run `python illustrator/generators/test_guide.py`, then open `illustrator/out/test_guide.svg` in Illustrator. Each `<g id="...">` becomes a layer.

## Install the panel
1. `powershell -File illustrator\install.ps1` (symlinks `panel/` into `%APPDATA%\Adobe\CEP\extensions\VarrenmoorBridge`, copies if symlinks are not allowed). No registry changes.
2. Read, then run once: `powershell -File illustrator\enable-debug.ps1`. It sets `HKCU\Software\Adobe\CSXS.11` and `CSXS.12` `PlayerDebugMode` = "1" (needed for unsigned extensions).
3. Restart Illustrator, then Window > Extensions > Varrenmoor Bridge. The panel is the tabbed control surface described under Panel GUI below; it also still runs job files dropped in `jobs/`.

## Test
1. Panel open. Copy the `ping` job below to `illustrator/jobs/t1.json`.
2. Within ~2 s it moves to `jobs/done/t1.json` and `jobs/done/t1.result.json` appears with `"ok": true` and the Illustrator version.
3. Then run the full example (new doc, layers, place the test SVG, save, PNG preview).

## Job format
File `jobs/<id>.json`; `actions` run in order and stop at the first failure unless `"continue_on_error": true`. Relative paths resolve from the repo root.

```json
{"actions": [{"action": "ping"}]}
```

```json
{
  "id": "test_guide",
  "actions": [
    {"action": "new_document", "width_in": 17, "height_in": 11, "landscape": true},
    {"action": "ensure_layers", "names": ["Grid","Roads","Walls","Buildings","Water","Labels","Notes"]},
    {"action": "place_svg", "path": "illustrator/out/test_guide.svg"},
    {"action": "save_ai", "path": "illustrator/out/test_guide.ai"},
    {"action": "export_png", "path": "illustrator/out/test_guide.png", "scale": 100}
  ]
}
```

`place_svg` opens the SVG, copies each layer's items into the active document's same-named layer, and closes the SVG. With `"mode": "open"` (or no open document) it just leaves the SVG open as its own document.

Result file: `{"id","ok","finished","results":[{"action","ok","error"?,...}]}`.

## World model and layered town SVG
- `python world/gen_bridgehollow.py` writes the river (`water.json`), `place.json`, then runs the town generator (below), which writes `streets.json`, `districts.json`, `buildings/*.json`, `town_gen_report.json`. Everything is `proposed`; deterministic by seed.
- `python illustrator/generators/render_world.py --view town` writes `illustrator/out/bridgehollow_town.svg` with the layer tree from DESIGN.md section 3. Views: `town`, `bowl`, `street:<street_id>`, `building:<building_id>`; output defaults to `illustrator/out/bridgehollow_<view>.svg` (`--out` overrides).
- Every shape is a closed path with `id` = entity id; strokes use classes `guide-line`, `wall`, `road`, `water`, `proposed`.

## Map scale and grid (`world/<place>/view_settings.json`)
Feet are the model unit; the view settings only change the drawing. `presets`: `town` 1 in = 100 ft (grid 100, major every 5), `bowl` 1 in = 200 ft (whole 2400 x 1500 ft place on 17x11), `street` 1 in = 20 ft, `room` 1 in = 5 ft (grid 5 ft = one Foundry square). Keys: `scale_ft_per_in`, `grid_ft`, `grid_major_every`, `focus` ([x,y] | `center` | `entity`), `scale_bar_ft`; file level: `units`, `page_in` [w,h], `margin_in`, `min_street_width_ft`, `contour_mask {enabled, include[]}`.
`render_world.py` options: `--preset town|bowl|street|room`, `--scale FT_PER_IN`, `--grid FT`, `--grid-major N`, `--page 17x11`. Grid lines (minor plus a heavier major path), scale bar, view window and label sizes (point sizes scale with sqrt(100/scale), clamped 0.6x to 1.6x) follow the scale. `viewcfg.py` is the loader; the town generator reads the same file.

## Town generator (`generators/town_gen.py`, params in `world/<place>/town_params.json`)
`python illustrator/generators/town_gen.py [--place P] [--params PATH] [--seed N] [--detail 1|2|3] [--preset ..] [--scale ..] [--dry-run]` or `python world/gen_bridgehollow.py`.
Pipeline: heightmap grids (slope, water, below-datum) -> A* main road from the entry (grade cap gives switchbacks; river crossing costs per foot so the bridge lands at a narrow, convenient spot) -> tensor field (ring tangent + overall grid + main road + river bank + contour direction weighted by slope + noise) -> streamlines per ring spacing, grade-capped by turning toward the contour, joined and pruned to the connected network -> plazas -> blocks (area minus streets, plazas, water margin) -> lots by oriented-box recursive cutting (idea from the Watabou TownGeneratorOS, GPL-3; fresh implementation, repository private and not distributed) -> buildings, fields, farmsteads, named buildings by lot scoring.
Output entities carry `elevation_ft` (streets also `elevations_ft` per vertex from the graded road bed, and `grade_max` over a 40 ft window; buildings `site_slope`, `site_relief_ft`). Elevations are signed feet against `sea_level_ft` (terrain meta, default 0): ground below the datum counts as water unless inside `limits.dry_basin_polys`.
Scale and detail: `detail` 1 = streets, squares, civic and named buildings only; 2 = plus houses, fields, farmsteads (default); 3 = plus sheds and finer street polylines. Street and lot sizes are always feet. The view scale only sets the street-polyline simplification tolerance (about 2.5 ft x scale/100); `min_street_width_ft` comes from view_settings.
Water enters only through `load_water()` (reads `water.json`: rivers as polygon and/or `centerline` + `width_ft`; lakes and sea as polygons with optional `elevation_ft`) and the `Water` class; replace that function to use another source.

`town_params.json` schema (all keys optional except `place`, `area_ft`, `entry.point`; defaults in `town_gen.DEFAULTS`):
- `seed`, `detail`, `view_preset`, `scale_ft_per_in` (override), `area_ft` (list of [x,y] feet; or `area_file`: path to such a JSON list, e.g. exported from a drawn closed path on a TOWN AREA layer).
- `output`: `streets, plazas, blocks` (block outlines, default off), `buildings, fields, districts` booleans.
- `limits`: `max_street_grade, max_main_grade` (rise/run), `max_build_slope, max_build_relief_ft, max_field_slope, hard_slope, water_margin_ft, bank_margin_ft, bank_fill_ft, below_datum_is_water, dry_basin_polys, flood_ft, min_street_width_ft`.
- `entry`: `point` [x,y], `via` [[x,y]..] waypoints, `name`, `id`, `width_ft`, `bridge_width_ft`, `bridge_cost_per_ft`, `smooth_samples`.
- `ring_spec`: `centre`, `aspect`, `noise`, `noise_period_ft`, `feather_ft`, `rings[]` of `{id, name, kind: civic|residential|farm, r_max, street_width, dsep: [along-contour, across], lot_area: [min, max], build_prob}` (values blend across the feather band; fields come from the `farm` ring lots).
- `streets`: `step_ft, min_length_ft, snap_ft, seed_jitter, noise_angle_deg, grid_weight, ring_weight, contour_weight, slope_lo, slope_hi, road_weight, road_decay_ft, river_weight, river_decay_ft, simplify_ft, chaikin`.
- `plazas`: `enabled, min_area_ft2` (no plaza below it), `per_area_ft2` (one more per this much area), `max`, `radius_ft`, `min_sep_ft`, `anchors[]` of `{id, name, type: road|road_end|junction, near}`.
- `lots`: `spread, angle_jitter_deg, min_frontage_ft, front_setback_ft, house_fill_w, house_fill_d, min_house_ft, field_bend_ft, field_hedge_ft, farmstead_prob, floors`.
- `named`: sizes for `warden_hall, magistrate_court, tax_office, lockup, inn, stables, meeting_hall, smithy, mill`, plus `market_plaza`, `court_plaza` ids.

Checks: `python illustrator/generators/test_town_gen.py` (determinism, unique ids, nothing in water or over the slope limit, one bridge, negative elevations, switchback route). `generators/preview_svg.py in.svg out.png` rasterises our SVGs with PIL for a quick look.
Bridgehollow v2: `illustrator/out/bridgehollow_town_v2.svg` (1 in = 200 ft, whole bowl) and `bridgehollow_town_v2_100.svg` (1 in = 100 ft), both with terrain contours masked under buildings, streets and plazas, made with `render_world.py --view bowl|town --contours`.

## Terrain and contours (step 1; all proposed)
- `world/bridgehollow/terrain_spec.json`: artist constraints (ridges, peaks, valleys, passes as polylines with heights, base plane, noise, erosion, seed).
- `python illustrator/generators/terrain.py [--cell 10]` writes `world/bridgehollow/terrain/heightmap.npy` (float32 feet), `heightmap_16.png` (16-bit, scaled by `terrain_meta.json`) and `terrain_meta.json`. Deterministic; about 0.2 s at 10 ft cells.
- `generators/contours.py`: contourpy lines (smoothed, Chaikin), minor/index intervals, collision-aware elevation labels on index contours, optional mask polygons.
- `python illustrator/generators/render_world.py --terrain` (regenerates heightmap + `out/bridgehollow_height.png` hillshade, overlays contours) or `--contours` (reuses the saved heightmap). Options: `--contour-mask` / `--no-contour-mask` (default from view_settings `contour_mask.enabled`; mask polygons = building footprints + street polygons + plazas, `include` selects), `--contour-interval 10`, `--index-interval 50`, `--label-size 6`, `--units ft|m`. Output `out/bridgehollow_terrain.svg`. Contour levels count from `sea_level_ft` (signed: negative levels and labels work, minus sign configurable, the datum contour is drawn with class `contour-datum`).
- New layers (always present, empty without the flags): `LINES/Terrain/Contours - Minor`, `LINES/Terrain/Contours - Index`, `LABELS/Labels - Elevation`. `LayerTree` now supports nested sublayers. The panel's `replace_layer` has not been tested on the third nesting level.

## More panel actions
- `replace_layer`: `{"action":"replace_layer","path":"illustrator/out/bridgehollow_town.svg","names":["Roads","Buildings","Labels - Buildings","NOTES"]}`. Opens the SVG, and for each named layer (sublayers are named individually, parents are not recursed) clears that layer's own items and redraws them from the SVG, creating the layer if missing. Layers named `ART ...` are refused and never touched. Lock state and visibility of the target layer are restored afterwards (`"restore_lock": false` leaves it unlocked). Fails if a name is not in the SVG unless `"strict": false`.
- `lock_layers`: `{"action":"lock_layers","names":["GUIDES","Grid"],"locked":true}` (`locked` defaults to true; false unlocks). Works on layers and sublayers.

## Panel GUI (tabs; plain HTML/CSS/JS, no build step, no CDN)
Files: `panel/index.html`, `panel/main.js` (UI), `panel/lib/core.js` (state defaults, page<->feet maths, one builder per job), `panel/lib/runner.js` (job runner), `panel/jsx/host.jsx` (ExtendScript actions), `panel/test/run_mock.js` (job-flow test with a mock host). The manifest enables Node and mixed context (`--enable-nodejs --mixed-context`, plus `--allow-file-access*`); after changing the manifest restart Illustrator.

**State.** Every control writes `world/<place>/panel_state.json` (debounced, so it persists between sessions). The place picker and the View box (`town | bowl | street:<id> | building:<id>`) sit at the top, with status, Cancel and a Log toggle. Errors (missing python, missing files, generator failures, Illustrator failures) show in a red line under the header; no alert/prompt dialogs are used anywhere.

**Jobs.** A button builds a job (a list of steps: write a file, run a Python script, call an Illustrator action) and the runner executes it: one job at a time (a second one is refused while one runs), Cancel kills the running Python process tree. Python is `python` from PATH (Scale tab > Python executable to change), started from the repo root with UTF-8. stdout/stderr stream to the log. Each run writes `jobs/done/panel_<timestamp>_<kind>.json` with the exact params, every command line with exit code and output, and the Illustrator replies. Illustrator steps that draw (`replace_layer`, `place_image`, `apply_fills`) are optional: if Illustrator has no open document the generator output is still written and a yellow warning is shown. Working files (SVGs, phases, polygons, town candidate) go to `illustrator/out/panel/<place>/` (git-ignored).

**Stale marks.** A yellow dot on the Contours, Shading and Town tabs means terrain or water changed since they last ran: applying/undoing/removing/reordering patches, regenerating the base terrain, carving, analysing water, adding rivers/lakes, changing the scale. Running the tab clears its mark (Layers > Clear stale marks resets all).

**Tabs**
1. Scale: preset (town/bowl/street/room loads that preset), scale ft/in, grid, major-every, page, units. Apply writes `view_settings.json` and regenerates Grid, Scale bar, North arrow, Bounds, NOTES (GUIDES is unlocked and relocked around it). Also Redraw all GEN layers (with contours) and New document + draw.
2. Terrain: base spec fields (seed, cell, base elevation, noise, erosion; Generate base terrain runs terrain.py then replays the patches onto it); patch list from `patches.json` with undo/redo, remove, move up/down, click to load a patch into the form; Add Patch form (raise and depress types, max/min, average, steepness, feather, roughness, seed, angle). Capture polygon takes the selected closed path or the path on layer `TERRAIN AREA` and converts page points to feet using the current view. Preview shows the hillshade PNG and the fit numbers in the panel (nothing saved); Apply saves the patch.
3. Contours: minor/index, units, label size, decimals, spacing, min length, along-line/upright, labels on/off, datum emphasis, mask on/off -> `render_world.py --contours ...` then `replace_layer` of the three contour layers.
4. Shading: phases from the preset dropdown (the six in `presets/terrain_phases`); per phase enable, name, texture, elevation min/max and slope min/max sliders (the end of the range means unbounded), blend widths, opacity, jitter; drag the handle or use the arrows to reorder; hillshade azimuth/altitude/strength. Render writes `phases.json`, runs shading.py at the current scale and dpi, and places the PNG on layer `ART - Shading` (created below LINES) at the rectangle from the `.json` bounds sidecar, replacing the previous image and locking the layer.
5. Water: sea level, river threshold, outlet width, inflow lines, delta, meander, carve bank, and the "use derived water" / "use carved terrain" toggles (these decide what every generator reads). Derive rivers (`water.py analyze`), Carve, Bridges report (table from `crossings.json`), Add river (Capture path = selected open path or path on layer `WATER DRAW`; width, end width, depth, flow, meander, join, carve), Add lake (Capture polygon; level or lowest rim, depth, kind).
6. Town: Capture lasso (selected closed path or path on `TOWN AREA`), seed, detail, entry point, plaza threshold, blocks/buildings/fields, grade and slope limits, contour mask, per-ring radius, street width and lot area (from `ring_spec`). Generate writes the candidate model to `illustrator/out/panel/<place>/town_candidate/` (`town_gen.py --out-dir`), draws it (`render_world.py --model-dir`) and enables Accept/Reject. The saved model in `world/<place>` is untouched until Accept (copies the candidate over it and saves the run parameters as `town_params.json`); Reject deletes the candidate and redraws the saved model. Fills per part (streets, plazas, buildings, fields, water): pick a texture or swatch; four presets in `presets/town_styles/*.json` (Ink plan, Parchment, Watercolour, Dark survey). `apply_fills` creates named swatches (`VB Streets - parch_light`, ...) from the texture's mean colour and assigns them, plus an optional line colour, to the items on the named layers (Roads without `sqr_` ids, Roads `sqr_*`, Buildings, Fences `fld_*`, Water). Fills are re-applied after each draw when "Apply fills after drawing" is on, because a redraw clears them.
7. Layers: lock/unlock GUIDES, show/hide LABELS, regenerate view, redraw all, open out folder, open job-log folder.
8. Foundry: place/scene/actor/item pickers (read from Foundry, cached), Export view, Push scene, Push tiles, token/actor/item push, opt-in auto-push on save. Runs `generators/foundry_push.py`; writes need Varrenmoor Bridge module 0.3.0 (`foundry-bridge/DEPLOY_MODULE.md`). See DESIGN.md section 7. CLI: `python illustrator/generators/foundry_push.py push-scene --image view.png --scene-name "Name"` (`--dry-run` previews). Tests: `python illustrator/generators/test_foundry_push.py`, `node --test foundry-bridge/module/module.test.mjs`.

**Styles template note.** Scripts can create swatches but not graphic styles, brushes or pattern swatches, so textures appear as flat swatches of their mean colour. Keep the stroke/graphic styles (`guide-line`, `wall`, `road`, `water`, `proposed`) in `illustrator/templates/varrenmoor.ait` and apply them by hand; the town style presets only set fill and line colour.

**New host actions** (host.jsx): `get_doc_info`, `get_selection {layer?, closed_only?, open_only?}` (path anchors with handles in document coordinates, plus the artboard rect), `place_image {path, rect, layer, below, name, lock, embed}` (rect in page points from the artboard's top-left), `apply_fills {assignments}`, `set_visible {names, visible}`. Page points map to feet with the `panelio.py view` output (`x0, y0, k, margin_in`); the document is assumed to be drawn with the same view as the panel's current Scale tab, on an artboard whose top-left is the page corner.

## One terrain loader (`generators/worldio.py`)
`load_terrain(place)` is used by `terrain.load_heightmap` (so `render_world.py` contours and `town_gen.py` follow it), `shading.py` and `water.py` (analysis and carving read the patched map). Sources: `base`; `patched` (`heightmap_patched.npy` when present, else base); `carved` (`out/water/<place>/heightmap_carved.npy`, else patched; a warning is printed if it is older than the patched map); `auto` = carved when `panel_state.json` `water.use_carved` is true, else patched. CLIs take `--terrain-source auto|base|patched|carved` (render_world, shading, town_gen) and `--water-source world|working` (render_world, town_gen; `working` reads `out/water/<place>/water.json` from `water.py`). Env `VB_TERRAIN_SOURCE` / `VB_WATER_SOURCE` set the same. The panel always passes both flags explicitly so each job log shows what was read. Other new flags: `render_world.py --label-decimals --label-spacing --min-contour-len --no-follow-line --no-upright --no-labels --no-datum --model-dir`, `town_gen.py --out-dir`, `terrain_patch.py rebuild|json`, `panelio.py textures|view|town-accept|town-reject|status`. Check: `python illustrator/generators/test_worldio.py` (temp copy of the world).

## Label offsets (leader lines)
Labels of closed shapes (districts, plazas, buildings, rooms) are tested for fit: the estimated text rectangle (plus `margin_pct`) must lie inside the shape. If not, the text is moved outside (8 directions, up-right preferred, growing distance up to `max_offset_pt`), avoiding other labels, street/contour labels, leaders and, when possible, other buildings/plazas, and a thin leader runs from the text to an anchor inside the shape (`<entity_id>_leader`, optional dot `<entity_id>_leader_dot`). Leaders live in `LABELS/Leaders`, so hiding LABELS hides both and Leaders can be hidden alone. Street and contour text is never offset. Settings: `view_settings.json` `label_offset` {enabled, style straight|elbow, stroke_width, margin_pct, max_offset_pt (page pt), dot}; CLI `--label-offset/--no-label-offset --leader-style --leader-width --label-fit-margin --label-max-offset --leader-dot/--no-leader-dot`; panel Contours tab "Label offsets" (saved in `panel_state.json` as `label_offset`). Code: `generators/label_offset.py`; check: `python illustrator/generators/test_label_offset.py`. Text width is an estimate (Arial metrics), so tight cases may differ slightly in Illustrator. The offset controls now live on the panel's Labels tab (state key `label_offset` unchanged).

## Textured full-map fills (default)
By default the town generator output is drawn as a map, not linework: `generators/fills_raster.py` rasterises every street, plaza, building, field and water polygon of the model at the view's dpi (default 200) and fills it with the texture of its type. Output is one RGBA PNG per category, covering exactly the SVG `Bounds` window (sidecar `fills.json` holds the bounds in feet, dpi and layer names), placed with `place_image` as `ART - Fill Fields`, `ART - Fill Water`, `ART - Fill Streets`, `ART - Fill Buildings` (bottom to top, all below LINES and above `ART - Shading`; each re-run replaces its image). Vector road edges, building outlines, labels and contours stay on top and stay editable; hide or replace any fill layer separately.

- **Type to texture** is data-driven: `presets/town_styles/full_map.json` has a `types` map (`streets`: road=cobble, street=gravel, lane=packed_earth, alley=mud, bridge=plank across the span; `plazas`: cobble; `buildings` by kind: house = thatch/shingle/timber (seeded per building, with tint jitter), civic = slate/red tile, inn = shingle, mill/barn/stable/shed = timber; `fields`: per-crop (tilled, wheat, pasture, crop_green, chosen per field id unless the field has a `crop`); `water`: river/lake texture with shallows, foam and mud banks). Each entry takes `texture` or weighted `textures`, `tile_ft`, `warp`, `tint`; any PNG in `presets/textures` works. Styles without `types` (Ink plan, Parchment, ...) remain the flat-colour presets.
- **Textures** are the 16 new seamless tiles written by `generators/make_fill_textures.py` (cobble, gravel, packed_earth, mud, plank, timber_roof, stone_slab, slate, shingle, red_tile, thatch, tilled, wheat, crop_green, pasture, water) next to the 20 existing ones. Sampling uses the shading's anti-tiling (domain warp + two blended copies, world-aligned so shapes of one type join without seams; structured textures like roofs and furrows skip the warp), mip-mapped so scale changes stay crisp, with a minimum tile size in pixels (`raster.min_tile_px`).
- **Look**: roofs are rotated to the building's long axis with ridge line, lit/shaded slopes, dark eaves and a drop shadow; fields run their rows along the long side with a hedge border; streets get a worn darker edge; the bridge casts a shadow; the river gets shallows, foam and banks.
- **Flat vector fills**: for every type used, a named swatch (`VB Roofs - slate`, `VB Streets - gravel`, ...) from the texture's mean colour, applied to flat fill-only copies of the shapes on layer `ART - Fill Shapes` (under the rasters; editable, usable as masks; replaced on each run). The line shapes themselves keep their outlines, because an opaque fill on LINES would hide the texture.
- **CLI**: `python illustrator/generators/fills_raster.py --place bridgehollow --view town --preset town [--scale 40] --out-dir illustrator/out/fills [--style full_map] [--dpi 200] [--model-dir DIR] [--only fields,water,streets,buildings]`.
- **Panel** (Town tab, "Map fills"): "Textured full-map fills" (on by default), "Apply fills after drawing" (on), style dropdown (every style with a `types` map), fill dpi, flat swatches, embed PNGs, and "Render map with fills". Fills also run after Generate / Reject and after "Redraw all GEN layers" and water redraws. The old per-part flat presets sit below as "legacy". New panel code: reopen the panel after updating (`host.jsx` is loaded at panel start).
- Samples: `out/bridgehollow_sample_fills.ai/.png` (bowl, 200 ft/in), `..._fills_town.png` (100 ft/in), `..._fills_town40.png` (40 ft/in); rasters in `out/sample/fills_*`.

## Label legibility (wrapping, halo, backing, knock-out, fonts)
Code: `generators/label_style.py` (styles, wrapping, SVG), integrated in `label_offset.py` (wrapped layouts are tried before a label is moved outside) and `render_world.py`; checks: `python illustrator/generators/test_label_style.py`.
- **Categories**: districts (districts + plazas), streets, buildings, rooms, elevation. Every key lives in `default` and can be overridden per category.
- **Fonts**: font family (Arial, Georgia, Times New Roman, Garamond, Palatino Linotype, Trebuchet MS, Verdana, Cambria, Constantia, Calibri, Tahoma, Candara, Baskerville), size (blank = follows the scale), bold, italic, letter spacing, case (auto = districts UPPER / as-is / UPPER / Title), colour, auto-contrast (dark text on a light halo/box, light text on a dark one). Families are written as SVG `font-family` plus weight/style; Illustrator maps them to the installed font (verified for Arial, Georgia, Trebuchet MS). Garamond and Baskerville are not in a stock Windows install; if missing, Illustrator substitutes. Host action `{"action":"list_fonts","names":["Garamond","Baskerville"]}` reports installed families / `missing` (available after the panel is reopened).
- **Wrapping**: `wrap` off | auto | width. auto tries 1 line, then 2..`max_lines` balanced lines (word boundaries, no hyphenation) and keeps the first that fits inside the shape; if none fits the one-liner is moved outside with a leader as before. width wraps to `wrap_width` (page pt or feet via `wrap_unit`), never exceeding `max_lines` (the block widens instead). `line_spacing` (x font size), `align` left|center|right. Multi-line text is one SVG `<text>` with `<tspan x dy>` lines; it opens in Illustrator as editable text with line breaks.
- **Backing** (`mode`): `none`; `halo` = a copy of the text under it with a round-joined stroke (`halo_color`, `halo_width`, `halo_opacity`; no `paint-order`, which Illustrator ignores); `box` = rounded rectangle (`box_color`, `box_pad`, `box_radius`, `box_opacity`); `mask` = invisible knock-out only. Backing shapes go to `LABELS/Label Backing` (toggle in Layers; `backing_layer: false` puts them under each text in its own label layer). Elevation backing stays in `Labels - Elevation`.
- **Knock-out** (`mode: mask`, or `knockout: true` with any mode): the label's padded rounded box (`knockout_pad`, pt) is subtracted with shapely from contour lines and from the targets in `mask_targets` (contours, streets, buildings, blocks, water, fences, grid; default contours, streets, buildings, blocks, grid). Lines become open sub-paths (real geometry, editable, no clipping paths). Elevation labels always cut their own contour (`knockout_pad` 1.5). Textured raster fills (`ART - Fill ...`) are NOT cut: use halo or box there.
- **Defaults**: soft white halo (90 %) on all but elevation, districts bold + letter-spaced, streets italic, text #111111, wrapping auto (3 lines districts, 2 buildings/rooms), knock-out off for area labels.
- **Config**: `view_settings.json` `label_style` {default, districts, ..., backing_layer, mask_targets}; CLI `--label-style '<json>'` / `@file` / `--label-style-b64` (what the panel sends). Panel: **Labels** tab (category picker, all controls above, offsets, knock-out targets) saved in `panel_state.json` under `labels`; **Redraw labels only** replaces the LABELS sublayers, Label Backing, Leaders and (option) the linework they cut (contours, Roads, Buildings, Walls, Blocks, Water, Fences, Grid). Reopen the panel to load the new tab and host action.
- Visual checks: `illustrator/out/label_test_*.png/.ai` (default town 40/100, box, mask, fonts, bowl).
